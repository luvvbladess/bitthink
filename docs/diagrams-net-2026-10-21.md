# Блок-схемы diagrams.net в вебе и BitClient

Добавлен `diagram_create` для веб-Оркестратора/Astra и нового BitClient. Инструмент создаёт редактируемый `.drawio` и экспортирует его настоящим draw.io Desktop в PDF, PNG, SVG. По умолчанию: исходник, PDF и PNG. Пользователь получает обычные файловые вложения.

Пример запроса: «Нарисуй блок-схему обработки заказа с ветвлением по наличию товара. Выдай PDF и PNG, приложи исходник diagrams.net».

Модель передаёт `path`, полный несжатый `xml` и необязательный массив `formats`. Вместо `xml` можно передать `source_path` существующего XML в рабочей среде для экспорта копии. PDF содержит все страницы; PNG/SVG — `page_index` с 1. До 30 страниц/2000 элементов на страницу, XML до 5 МБ. В вебе экспорт ограничен 8 МБ на файл. Исходники и готовые файлы не перезаписываются. Сервер принимает самодостаточные схемы без внешних изображений и ссылок.

Веб: `computer_tools` → `sandbox_client` → операция `diagram` → `bt_diagrams` в sandbox. Временные файлы и профиль движка находятся в `/tmp`; HOME/XDG направлены туда же для контейнера с read_only. Один экспорт одновременно, до 55 секунд на формат. В образ встроены draw.io 32.5.5, Xvfb и шрифты с кириллицей. Сборка проверяет SHA-256 официального DEB. Базовый образ закреплён на Debian bookworm для совместимости библиотек Electron.

BitClient: локальный инструмент и файловые события для каждого результата. При отсутствии установленного draw.io автоматически загружается официальный Windows ZIP 32.5.5 (~180 МБ), проверяется SHA-256 и распаковывается в userData/runtime. Дальнейший экспорт работает офлайн. В режиме «только чтение» инструмент недоступен. Старым клиентам инструмент не предлагается.

## Проверка

- `npm run build` в BitClient: TypeScript, renderer и Electron bundles.
- `node scripts/smoke-diagrams.mjs` в BitClient: реальное приложение, автоматическая загрузка runtime, PDF/PNG/SVG с кириллицей, исходник/копия, файловые карточки, запрет перезаписи, невалидный XML, readonly.
- `python -m unittest discover -s sandbox -p test_diagrams.py -v` в bitthink: валидация, границы пользователей, выдача исходника/SVG, откат неудачного экспорта, маршрутизация веб-режима.
- С `DRAWIO_BINARY` тесты также запускают настоящий движок и проверяют многостраничный PDF, PNG/SVG второй страницы и выдачу всех четырёх файлов. Проверено на Windows; при выкладке также проверен настоящий Linux-контейнер с read_only, без сети и с ограничениями памяти/процессов.

## Включение на рабочем сервере

Обновления backend и sandbox выложены 21.10.2026. Опубликован BitClient 0.8.29, обновлены страница скачивания и канал автообновления. Прочие локальные незакоммиченные изменения проекта не включались: серверные файлы изменены по проверяемым точечным заменам.

После согласования состава серверных изменений собрать `docker compose build backend sandbox`, затем перезапустить эти два сервиса. В рабочем дереве есть другие незакоммиченные изменения; перед выкладкой проверить их состав и не включать их автоматически в этот релиз. Проверить `/health` sandbox и реальный веб-запрос на создание схемы с четырьмя вложениями. Для пользователей BitClient также выпустить обновлённую сборку клиента.

Исходники движка/лицензия: [drawio-desktop v32.5.5](https://github.com/jgraph/drawio-desktop/tree/v32.5.5). Формат файла: [draw.io File Format](https://github.com/jgraph/drawio/wiki/File-Format). Экспорт: [официальное описание форматов](https://www.drawio.com/docs/manual/export/export-diagram/).
