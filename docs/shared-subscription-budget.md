Платные тарифы используют один ресурс для чата, Оркестратора и Студии.
Изображения учитываются отдельно; цены и доступные модели не менялись.

16 октября по решению владельца месячные бюджеты увеличены примерно на 25%,
недельные — вдвое. Пятичасовой ресурс сохраняет удвоенную сумму прежних окон.
Trial использует значения Pro+.
Ни счётчики, ни действующие резервы не обнуляются: хранение по двум режимам
сохраняется, проверка остатка складывает их под той же блокировкой подписки.
Возврат резерва остаётся в исходном режиме с проверкой периода/окна/тарифа.
Это предотвращает повторное расходование общей квоты параллельными вызовами.

API добавляет shared_budget, shared, breakdown и windows.shared. Для старых
клиентов chat/computer и их окна показывают одинаковый общий остаток.
Каталог добавляет total_tokens, weekly_tokens, session_tokens; прежние поля
раздельных распределений оставлены для совместимости. Новая витрина использует
общие поля, а не сумму двух копий совместимого остатка.

Базовый тариф: 30 ответов в сутки, из них не более 15 поисковых. Существующие
daily_gpt54 (обычные) и daily_nano_mini (поисковые) суммируются для общего
дневного расхода. Перед ответом атомарно резервируется обычный ответ. При первом
реальном поиске он атомарно переводится в поисковую часть. Несколько запросов,
движков, повторное использование кеша и дочерние задачи с тем же резервом
не увеличивают число ответов. Неудавшийся/отменённый ответ возвращает свой резерв
один раз; возврат после полуночи не уменьшает счётчики нового дня.

Собственный поиск убирает плату поисковому API, но не токены моделей на запрос,
обработку материалов и финальный ответ. Поэтому месячный/недельный максимум
увеличен по решению владельца после исследования фактической нагрузки,
а не на основании предположения о нулевой себестоимости поиска.

Проверки: общая квота, сохранение истории, гонка чата с Оркестратором за последний
резерв, расчёт и возврат каждого хода модели, бесплатные 15 из 30, параллельные
поиски в одном ответе, кеш и возврат при ошибках. Кабинет проверен на desktop/mobile
в светлой и тёмной темах; сборка TypeScript/Vite проходит.
