# BitClient 0.9.2: браузер, изображения и управление компьютером

## Причины ошибки на скриншоте

- SVG-логотип не входил в список форматов `desktop_image_read`. Файл был корректным; ошибка выдавалась до попытки его отрисовки.
- PDF весил 29 348 100 байт и отсеивался общим лимитом 20 МБ, хотя постраничный рендер уже ограничивает размер изображения для ИИ.

## Исправления

- Добавлена локальная растеризация SVG в отдельном worker. Главный процесс не занят отрисовкой; действуют ограничения размера файла, числа пикселей, времени и отмена операции. Подготовленная картинка проходит прежнее ограничение передачи в ИИ.
- Визуальное чтение PDF допускает до 100 МБ, как существующее преобразование PDF в текст. Читается выбранная страница; размер картинки, время рендера и объём данных для модели по-прежнему ограничены. Для обычных изображений сохранён лимит 20 МБ.
- Ошибки различают неподдерживаемый формат, папку вместо файла и превышение лимита PDF/изображения.
- Исправлена активация окна через `desktop_control focus`: для активации самого окна элемент необязателен; корневой элемент окна не получает ошибочный `SetFocus`, когда он не поддерживает клавиатурный фокус. Фокус конкретного элемента по актуальному идентификатору сохранён.
- Локальные инструкции различают снимок сайта и изображения проекта: внешний вид страницы проверяется по `desktop_browser_inspect screenshot=true`, затем `screenshot.path` передаётся на визуальный анализ.
- Установщик содержит новый SVG-worker; проверка упаковки сравнивает его, PDF-worker и мост Windows с текущей сборкой.

Клиентский исходный проект расположен отдельно: `E:/progs/BitClient`. Серверные маршруты, модели и тарифы этого выпуска не менялись.

## Подтверждённые проверки

1. Исходные SVG и первая страница PDF из пользовательского примера прочитаны локально без изменения файлов и отправки их содержимого внешней модели.
2. В реальном Electron проверены пиксели SVG, вложение `attachment://`, фрагмент изображения, PDF больше 20 МБ, текстовая и сканированная страницы, повреждённые документы, неверная страница, лимиты и отмена.
3. Через реальные инструменты продукта в отдельном окне Windows выполнены `desktop_inspect → desktop_control focus → desktop_capture → desktop_image_read → desktop_pointer`. Проверены движение мыши, ввод русского текста, клик, двойной и правый клик, перетаскивание и фактическая прокрутка. Состояние элементов подтверждает результат; геометрия снимка сопоставлена с физическими пикселями.
4. Отдельный тест Windows проверяет остановку ввода и отпускание кнопки мыши при прерывании перетаскивания.
5. Браузерные тесты проверяют Edge/Chrome, актуальные ссылки на элементы, iframe, ввод и клики, загрузки, скачивание, профиль и снимки desktop/mobile/полной страницы.
6. Клиентский транспорт в режиме «Только чтение» не рекламирует управление мышью и отклоняет присланный вызов `desktop_pointer` до выполнения.
7. Через основной сервер выполнен настоящий вызов визуальной модели по снимку синтетической страницы из браузера Бит Клиента. Модель прочитала заголовок «Проверка распознавания» и сумму 12 500 рублей. Временный аккаунт и серверная копия тестового изображения удалены.
8. Прошли проверка типов, сборка, локальные инструменты и полный интерфейсный прогон клиента: режимы, потоковый ответ, сохранение позиции, темы, настройки, файлы, черновики и изоляция аккаунтов.

Это проверка реальных механизмов Windows в контролируемом окне, а не обещание безошибочной работы ИИ во всех приложениях. UAC, поля пароля, различия прав процессов, смена фокуса и перекрывающие окна сохраняют существующие ограничения. При потере фокуса или перекрытии действие останавливается; согласование действий не отключено.
