# Сохранение полезного ответа при работе с источниками

Причина пользовательского инцидента: финальная проверка могла заменить весь ответ фразой «Проверенных данных для точного ответа пока недостаточно…» из-за отсутствия ссылок у отдельных строк. Количество найденных источников не позволяло понять это поведение пользователю.

Изменения:

- Если есть успешно прочитанные страницы, размещение ссылок считается рекомендацией по оформлению. Само по себе оно больше не запускает повторный модельный проход и не стирает ответ. Панель источников остаётся доступной.
- Действительно полученный поисковый черновик вместе с наблюдениями передаётся в общую ограниченную процедуру исправления. Раньше он отбрасывался и запускался второй полный поиск.
- Сохраняются проверки неизвестных URL, точных сведений со ссылкой только на непрочитанный результат, неподтверждённых дат публикации и исторических условий вместо текущих тарифов. Успешное чтение страницы не объявляется доказательством всех утверждений модели.
- Неподтверждённые цены и наличие необходимо явно отделять от рекомендации; это требование к ответу модели остаётся в инструкциях. Структурная проверка не гарантирует семантическую достоверность ответа.
- Псевдовызовы инструментов в тексте ответа не принимаются за готовую рекомендацию.

Добавлено пять регрессионных проверок: ответ без построчных ссылок при прочитанных страницах; сохранение предупреждений для непрочитанных цен; рекомендация телефона без дополнительного модельного вызова; одно исправление неизвестной ссылки с сохранением наблюдений; отклонение псевдовызовов инструментов.

Интерфейс, тарифы, модели провайдеров и схема базы этим выпуском не меняются. Старые сохранённые ответы автоматически не переписываются.

Проверки кандидата: 966 серверных тестов на новой изолированной PostgreSQL, 137 проверок качества и 5 сценариев с экспортом Word прошли. На мигрированной копии базы сохранены 6947 записей в 33 существующих таблицах.
