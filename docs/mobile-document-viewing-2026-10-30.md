# Документы и открытие результатов на телефоне

Опубликовано на https://bit-think.space 30 октября 2026 года.

## Пользовательский путь

- У готового файла две независимые кнопки высотой 48 px: **Открыть** и
  **Скачать**. Название занимает до двух строк, тип результата и размер
  вынесены отдельно. Редактирование и удаление из контекста остаются
  отдельными действиями.
- На телефоне открывается полный экран с кнопкой закрытия. Черновик чата
  сохраняется после просмотра.
- DOCX на телефоне по умолчанию открывается в режиме **Чтение**: выделяемый
  текст по ширине экрана, шрифт 16–24 px, заголовки, выделения, ссылки,
  списки, изображения и таблицы. Размер текста сохраняется на устройстве.
- Широкие таблицы прокручиваются в своей области. Место чтения сохраняется
  при переключении в **Оригинал** и обратно.
- На компьютере DOCX по умолчанию открывается в OnlyOffice только для
  просмотра. На телефоне тот же вид доступен кнопкой **Оригинал**.
- HTML-результат открывается в изолированном холсте прямо из карточки,
  в том числе в Оркестраторе. Выбор режима «Студия» для этого не требуется.
  Только что полученный HTML доступен и из живого ответа, до обновления истории.

## Содержимое и доступ

Режим чтения отдаёт структурированные данные, не HTML документа. Удалённый
текст правок скрыт; вставки показываются. Сохраняются номера, уровни и
перезапуски списков, включая римские числа и буквенные обозначения.
Объединённые ячейки не дублируются, изображения получают исходное соотношение
сторон, текст сносок добавляется в конец.

Режим чтения адаптирует оформление для экрана. Колонтитулы, комментарии,
математическая разметка и сложные плавающие объекты помечаются как доступные
в «Оригинале». Исходный документ и скачивание не меняются.

Изображения доступны по подписанным ссылкам для конкретного документа и
беседы с проверкой хеша версии. Чужая беседа и устаревшая версия отклоняются.
Внешние связанные изображения не загружаются сервером. Исполняемые ссылки
из DOCX исключаются; документный HTML не вставляется в DOM приложения.
HTML-холст работает в `sandbox="allow-scripts"` без доступа к DOM приложения.

## Проверка

- 26 серверных тестов прошли внутри подготовленного Linux-образа с отдельной
  тестовой БД. Проверены структура DOCX, безопасные ссылки, изображения,
  слияния ячеек, списки, просмотр Word, прежние PDF/Excel и редактор.
- 25 целевых проверок интерфейса: 6 для чтения DOCX в обеих темах,
  3 для отдельных кнопок HTML/Excel и живого HTML, 9 для библиотеки,
  4 для прежнего предпросмотра/Студии и 3 для просмотра таблиц.
- После публикации проверен существующий DOCX из библиотеки: оригинал в
  реальном OnlyOffice на компьютере и телефоне, адаптированное чтение,
  вертикальный сенсорный жест и возврат к сохранённому месту.
- Отдельный настоящий DOCX с иллюстрацией проверен через опубликованный API
  и интерфейс: изображение загружается, устаревший хеш отклоняется,
  скачивание совпадает с исходником побайтово. Анонимный запрос запрещён.
- Существующий HTML-результат Оркестратора открывается кнопкой «Открыть»;
  дождались отображения активного слайда, снимок сохранён для проверки.
- Снимки находятся в игнорируемых `test-results/docx-reader/` и
  `test-results/mobile-open/`.

Мобильные проверки выполнены в Chromium с эмуляцией размеров и сенсорного
ввода, включая ширины 320 и 390 px. Физический телефон в этой проверке
не использовался. Сложное оформление всегда можно сверить в «Оригинале».

Предыдущие серверный образ и исходники сохранены в
`/root/bitthink-reader-backup-20261030`, предыдущая версия карточек — в
`/root/bitthink-mobile-open-backup-20261030`. Старые ресурсы оставлены для
открытых вкладок. Для появления нового интерфейса в старой вкладке нужно
обновить страницу.
