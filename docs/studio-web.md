# Интернет в Студии

Студия использует поиск и чтение страниц прямо в существующем вызове сборки HTML
или JSON для PPTX. В новых макетах и их правках доступны только инструменты чтения:
web_search/server_search, browse_page, чтение файлов чата и привязанного проекта.
Команды, коннекторы, публикация и изменение навыков в этот вызов не передаются.

Для цен, тарифов, статистики, рынка, законов, новостей и явного запроса найти
данные первый поиск обязателен. Модель затем точечно открывает первоисточники.
До трёх URL, явно указанных в самом задании, читаются до композиции параллельно:
обычные страницы ограничены 12 секундами, магазины — 25 секундами на запрос.
Успешно прочитанный первоисточник из задания заменяет обязательный первоначальный
поиск. Ошибки чтения передаются модели явно.
Обычно хватает 1–2 поисков и 1–3 страниц; это рекомендация в инструкции,
а жёсткий предел — четыре модельных хода с последним ходом для итогового материала.
Каждый ход может содержать несколько вызовов инструментов.
Простые правки оформления не требуют поиска, а «без интернета» отключает его.
Проверка перед рисованием изображения вызывается только для актуальных фактов.

Источники возвращаются в обычную панель чата вместе с макетом. Состояния «выдача»,
«страница прочитана» и «ошибка чтения» получаются из фактического реестра вызовов,
а не из слов модели. Инструкция требует URL возле внешнего факта в макете или
в тексте соответствующего слайда. Это не автоматическое доказательство каждого
утверждения: качество привязки фактов к источникам остаётся ответственностью модели.
При недоступном источнике данные должны быть помечены как непроверенные.

Серверный поиск остаётся основным. Выдача не обходится автоматически; домашний
читатель используется существующим транспортом только для российских магазинов.
В пределах хода сохраняются ранее внедрённые кэши поиска и чтения страниц.
При ремонте HTML/JSON уже полученные источники передаются модели повторно.
Тарифный пул, выбор моделей и внешний вид режимов не меняются.

Проверки: test_studio_web.py исполняет цепочку Studio → Responses → поиск →
чтение → HTML → источники для создания и правки, ограничения набора инструментов,
PPTX-композицию, изображение с актуальными данными, отказ от обязательного поиска
для оформления и запрета сети, а также ошибку чтения. API модели и веб-ответы
в этих тестах подменены; рендер PPTX/PNG проверен существующими тестами Студии.
