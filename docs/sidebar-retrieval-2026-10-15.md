# Исправления проектов и чтения сайтов

Проекты показывают принадлежащие им личные беседы и счётчик. Перенос доступен
перетаскиванием или через меню «…» → «Переместить в проект». Удаление привязки
не удаляет беседу. Общие беседы исключены сервером из личной памяти проектов.
Сверху создаётся отдельный новый вопрос, внутри папки — беседа этого проекта.

GET /projects возвращает chat_ids одним дополнительным запросом, ограниченным
проектами владельца; перенос использует существующий проверяемый PUT /projects/chat/{id}.
После переноса обновляются список проектов, привязка беседы и рабочие области.
При сетевой ошибке нет оптимистического исчезновения беседы.

Чтение HTML сохраняет заголовки и границы строк/столбцов таблиц, в том числе
таблиц рядом со статьёй, а также имена из alt и ссылки на дальнейшие разделы.
Выдержка таблиц ограничена 6500 символами, 8 таблицами, 60 строками каждой;
общий существующий лимит страницы не увеличен. Поддержан публичный JSON
в существующем инструменте чтения с его проверкой публичного адреса.

Ответы инструментов при антиботе больше не инструктируют модель сразу просить
скриншот. Правила выполнения требуют ограниченного уточнения поиска по пробелу,
альтернативного источника и полезной частичной инструкции. Общие объяснения
отделяются от текущих статистик и неизвестных деталей версии. Без фильтров
рейтинга выбирается общая выборка, которую нужно явно назвать.

Ограничения: это не универсальное исполнение JavaScript и не обход антибота.
Изменение правил не гарантирует получение любых данных или правильность каждого
ответа модели. Числа и особенности конкретного патча нельзя придумывать.
Обычные сайты не отправляются в домашний браузер.

Проверка: 114 локальных backend-тестов; TypeScript и production build;
браузерные сценарии переноса меню/перетаскиванием, снятия привязки, ошибки API,
группировки, отсутствия горизонтального переполнения, desktop/mobile и светлая тема.
Сценарии интерфейса используют явные тестовые данные, не переписывают пользовательские беседы.
