# Управление проектами и поисковый контур

У проекта одинаковое меню в боковом списке и в рабочей области: переименование
и удаление. Удаление требует отдельного подтверждения, по умолчанию фокус на
«Отмена». Беседы и их вложения сохраняются; связи с проектом снимаются.
Материалы, версии, поисковые фрагменты и память удаляемого проекта удаляются.
Проверяется владелец, запись блокируется при изменении и удалении. Удаление
проектных копий файлов ограничено его приватной плоской папкой. При ошибке
очистки сервер сообщает cleanup_pending; интерфейс не скрывает это состояние.

Серверный поиск остаётся бесплатным метапоиском. Ранжирование больше не
принимает одно совпадение неоднозначного имени для многословного запроса;
чистые годы не повышают релевантность, точные артикулы сохраняют приоритет.
Это лексический фильтр, не полноценная семантическая модель.

Ключевое исправление маршрутизации: force_web раньше оставлял web_search
и навыки, исключая browse_page. Теперь исследователь получает server_search
и browse_page; автоматического массового обхода страниц не добавлено.
Web_search при WEB_SEARCH_BACKEND=server по-прежнему вызывает собственный поиск.

Короткий вопрос получает одного исследователя. У него до шести шагов вместе
с итоговым ответом. Ссылки сами по себе больше не закрывают ранний отказ:
предусмотрена одна дополнительная попытка поиска/проверки без дорогого
повторного планирования. Полезный частичный ответ не запускает её.
Проверяющий должен перепроверить тему, а не открывать все нерелевантные ссылки.

Сохранён и исправлен адаптер Kimi: убрано требование пяти источников,
добавлено сохранение контекста и чтение найденных страниц. После последнего
разрешённого вызова инструмента данные включаются в завершающую выжимку,
вместо возврата старого промежуточного текста.

Найденное значение нужно давать вместе с выборкой и периодом. Если источник
не называет патч, это отдельное ограничение, а не повод скрыть доступную
статистику. Для тарифов сравниваются подтверждённые варианты и условия,
не обещается безлимит. Неполученные сведения нельзя придумывать.

Проверки включают отсечение магазинов Melissa и mobile.de, недостаточность
общей страницы GitHub для запроса тарифа Copilot Pro, сохранение точного MPN,
доступность чтения в поисковом режиме, передачу последнего результата Kimi,
ограниченность повторной попытки и приватное удаление проекта с сохранением
беседы. Браузерные сценарии проверяют переименование, пустое название,
отмену удаления, ошибку API, закрытие удалённого проекта и сохранение беседы.
