# Проверка навигации и архитектуры — 25 октября 2026

## Вывод

Текущий стек позволяет обеспечить стабильную навигацию. Исправления касаются
владения состоянием, последовательности запросов и восстановления ошибок;
замена React для них не требуется.

Проверены маршруты входа, регистрации, чата, настроек, кабинета и администрирования,
переходы между беседами и проектами, новые чаты, черновики и вложения, фоновые ответы,
восстановление авторизации, сетевые отказы, документы и мобильные элементы управления.

## Исправления

| Ситуация | Результат |
| --- | --- |
| Медленно сохраняется выбранная беседа | История открывается независимо от этого запроса; сохранение выполняется в фоне. |
| Быстро выбраны разные беседы | Запросы сохранения выполняются последовательно, последний выбор остаётся последним на сервере. |
| Ссылка на беседу, Назад/Вперёд, обновление | Идентификатор сохраняется в адресе, восстанавливаются правильная беседа и её черновик. |
| Возврат из настроек до завершения сохранения выбора | Последняя беседа помнится отдельно для аккаунта и вкладки; возврат не зависит от устаревшего серверного выбора. |
| Создание нескольких чатов подряд | Старый адрес не отменяет новую беседу, пока маршрутизатор завершает переход. |
| Сбой загрузки списка бесед | Показана ошибка с повтором запроса вместо ошибочного экрана нового чата. |
| Сетевой запрос навигации завис | Список, история и сохранение выбора ограничены 15 секундами; неактуальные запросы чтения получают сигнал отмены. |
| Не загрузился код раздела | Возможна одна автоматическая перезагрузка документа за 60 секунд, затем доступно ручное восстановление; нет бесконечного цикла. |
| Есть неотправленные вложения | Автоматическая перезагрузка отключена, чтобы сохранить File-объекты; можно вернуться в чат с тем же текстом и файлами. |
| Ошибка отрисовки компонента | Сообщение не обвиняет соединение; доступен повтор открытия раздела без перезагрузки всего приложения. |
| Новый раздел после длинной страницы | Открывается с начала; изменение беседы не сбрасывает прокрутку окна. |

## Границы состояния

- Адрес описывает открытую беседу. Последняя беседа в sessionStorage — резерв
  для перехода на `/chat` без параметров, с ключом аккаунта и отдельной областью вкладки.
- React Query хранит серверную историю и данные разделов. Сохранение активной
  беседы не блокирует чтение истории.
- Соединение чата принадлежит авторизованной сессии, поэтому настройки и кабинет
  не закрывают сокет. При возврате используются сохранённая история и снимок задач.
- Черновики принадлежат аккаунту и беседе. Текст переживает перезагрузку,
  неотправленные файлы остаются в памяти до отправки или удаления.
- Предзагрузка и открытие раздела используют общий обещанный результат загрузки.
  Неудачная предварительная загрузка не сохраняется в этом прикладном кеше навсегда.
- Выкладка сохраняет предыдущие файлы с хешами и публикует новый index.html
  после зависимостей; существующие вкладки продолжают получать свои файлы.

## Проверки

- Производственная сборка и TypeScript: успешно.
- Полный набор проверок интерфейса в Chrome: **98 прошли**, неожиданных исключений нет.
- На собранном приложении: **13 проверок навигации** и **4 проверки временных
  отказов авторизации** прошли.
- Проверены оба класса ошибок: искусственный обрыв загрузки модуля и искусственное
  исключение отрисовки. Их ожидаемые исключения исключаются только из соответствующих
  тестовых сценариев; остальные ошибки браузера по-прежнему приводят к провалу набора.
- Проверены ширины 320, 390 и 1440 пикселей, светлая и тёмная темы, доступность
  кнопок восстановления и отсутствие горизонтального переполнения.
- Механическая проверка изменённого экрана восстановления: замечаний нет.

Тесты интерфейса используют контролируемые ответы API и обрывы сети. После выкладки
дополнительно проверяются публичные маршруты, файлы сборки, здоровье API и переходы
в опубликованном интерфейсе. Историческое исключение со скриншота не установлено:
сам скриншот не содержит стека ошибки, а доступ к той вкладке Chrome был недоступен.
