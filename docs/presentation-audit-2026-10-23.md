## Что показала оценка интерфейса

Общий визуальный язык узнаваемый: спокойный фон, один акцент, понятный центр работы — беседа. На телефоне проект занимает отдельный экран, на широком мониторе материалы доступны рядом с беседой. Таблица ограничивает горизонтальную прокрутку своей областью. В просмотренных снимках основные действия не выходят за экран.

После исправлений вход, кабинет, настройки и работа с результатом проекта согласованы по цвету и состояниям ошибок. Сохраняются текст при отказе операции, понятный повтор и защита от случайного повторного зачисления фоновой задачи.

Отдельно проверены:

- повтор регистрации задачи Оркестратора после 503: черновик сохранён, используется тот же ключ идемпотентности;
- пауза и возобновление фоновой задачи с мобильного экрана;
- отказ правки изображения: описание сохранено, повтор использует исходную картинку и ту же беседу;
- отказ разбора документа: материал не привязывается к проекту;
- конфликт версии таблицы: правки остаются в форме; последующий успешный запрос отправляет ожидаемую версию;
- ошибка кабинета: повтор возвращает настоящий тариф;
- переход по приглашению через форму входа;
- вход через публичное мобильное меню.

Нулевой результат axe не означает, что все touch-цели во всех редакторах имеют 44×44 или что все сценарии удобны со скринридером. Вне выбранных состояний это не утверждается.

## Что закрыть до показа

### P1: репетиция на опубликованной версии

Сначала опубликовать проверенный набор изменений обычным релизным процессом. Затем на отдельном демонстрационном аккаунте пройти реальные сценарии с теми же файлами и запросами, которые будут на сцене:

| Сценарий | Что должно получиться |
| --- | --- |
| Обычный чат | Ответ приходит потоком; остановка и продолжение беседы работают |
| Поиск | Открываются настоящие источники; проверяется содержание, а не только наличие ссылки |
| Документы | TXT/PDF/DOCX/XLSX загружаются и используются в ответе; исходник и цитаты доступны |
| Проект | Документ появляется в материалах и доступен в другой беседе проекта |
| Таблица/отчёт/презентация | Результат сохраняется, правится, скачивается и открывается соответствующей программой |
| Изображение | Настоящая генерация и правка завершаются, скачанный файл открывается |
| Оркестратор | Реальная задача выполняется; видны результат, пауза, возобновление и возврат после перезагрузки |
| Вход и приглашение | Аккаунт повторно входит, приглашение открывает нужную беседу |

Нужны действующий демонстрационный тариф, достаточные лимиты, доступность провайдеров и сервисов обработки документов. Подставной браузерный API этого не доказывает. Production PostgreSQL, sandbox и подключение BitClient в этом проходе не запускались.

### P1: физические мобильные устройства

Пройти те же главные сценарии на iPhone/Safari и Android/Chrome. Проверить открытие клавиатуры, длинный ввод, выбор файла, скачивание результата, системный масштаб, микрофон, уход в другое приложение и возврат. Проверка равенства функций на компьютере и телефоне пока подтверждена только для покрытых браузерных сценариев.

### P1: вход при забытом пароле

Самостоятельного восстановления по-прежнему нет. Сообщение «напишите администратору» не содержит конкретного канала. Для действующих клиентов нужен настроенный путь восстановления; контакт нельзя выдумывать. Для презентации заранее проверить вход демонстрационного аккаунта.
