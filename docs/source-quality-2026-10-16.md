# Работа с источниками: исследование и исправления

Дата: 16.10.2026. Публичная документация описывает доступные принципы/API,
а не всю закрытую архитектуру потребительских приложений конкурентов.

## Что подтверждено документацией

- Perplexity предоставляет фильтры доменов, даты публикации/обновления,
  относительной свежести и местоположения. Эти параметры нужны для отбора
  подходящих свидетельств; количество результатов само по себе ничего не доказывает.
  [Web Search](https://docs.perplexity.ai/docs/agent-api/tools/web-search).
- Claude сохраняет содержимое поиска и ссылки между ходами: API требует
  возвращать исходные блоки с encrypted_content и метаданными цитат.
  Это подтверждает важность передачи доказательств, а не только текста ответа.
  Наш провайдерский протокол другой, поэтому перенесён принцип сохранения
  происхождения, а не чужой формат encrypted_content.
  [Web search tool](https://platform.claude.com/docs/en/agents-and-tools/tool-use/web-search-tool).
- OpenAI разделяет полный список найденных URL и ссылки, использованные
  в ответе. Документация цитирования рекомендует привязывать утверждения
  к конкретным документам/фрагментам, проверять релевантность и качество источника.
  [Web search](https://developers.openai.com/api/docs/guides/tools-web-search),
  [Citation formatting](https://developers.openai.com/api/docs/guides/citation-formatting).
- Проверена также документация Google по привязке ответа к веб-источникам:
  [Grounding with Google Search](https://ai.google.dev/gemini-api/docs/google-search).
  Не заявляется воспроизведение внутреннего алгоритма Google/Perplexity.

## Наблюдавшийся сбой

В беседе о Muse Wonder предыдущий ответ имел реальное чтение официального
анонса Meta. На запрос «а скажи именно версии моделей, циферные» свежий поиск
не требовался прежним маршрутизатором. Сохранённые источники не попадали в
контекст следующего хода; модель получила предыдущую прозу, а не наблюдения,
и без новой проверки назвала предыдущие ответы выдумкой.
Существование модели независимо подтверждено чтением
[анонса Meta](https://about.fb.com/news/2026/10/introducing-muse-wonder-models/).

## Реализовано

1. Ограниченный контекст источников для связанных уточнений: до четырёх
   записей, до 6500 знаков данных, реальные URL, статусы read/retrieved и время
   получения. Предпочитаются прочитанные страницы; поисковая выдача не
   превращается в прочитанную страницу. Восстанавливается также один предшествующий
   ход после неподтверждённого отрицания. Новая тема не подхватывает источники
   автоматически. Данные берутся только из текущей, уже авторизованной беседы.
2. Уточнения о версиях, ценах, конкурентах и точных данных требуют веб-маршрута,
   когда продолжают обсуждение с источниками. Пояснение/сокращение не требуют
   обязательного повторного поиска. Короткий Kimi-контекст сохраняет этот блок.
3. Общие правила выбора и использования источников для пользовательских
   модельных маршрутов: первоисточник для условий/анонса, независимые оценки для
   сравнений; точная версия и выборка; различие даты публикации и получения;
   ссылки возле подтверждаемых фактов; содержимое страницы не инструкции.
   Внутренние JSON-планировщики без веб-инструментов не получают новую задачу поиска.
4. Проверка ответа Kimi больше не считает длину текста и число URL доказательством.
   Принимается короткий ответ с одной реально полученной ссылкой; десять источников
   без связи с ответом недостаточны. minimum_sources оставлен совместимым аргументом.
5. Извлечение URL из модельного текста больше не создаёт «полученный источник».
   Номерные ссылки переводятся в Markdown только при явной карте номер→URL и
   наличии URL среди реальных результатов. Порядок разных поисковых выдач
   не используется как неявная карта номеров.
6. Один ограниченный проход перепроверки при наблюдаемом дефекте: нет ссылки
   на полученные материалы, ссылка не получена инструментом, либо идёт отрицание
   предыдущего ответа с источниками. Доступны только поиск и чтение; максимум
   четыре модельных хода и 55 секунд. Обычный ответ с корректными ссылками не
   получает дополнительный проход. При ошибке/таймауте проверки не заявляется успех.
7. Повторно используемые источники сохраняют прежнее время и origin=history,
   cached=true. Они не считаются новым посещением и включаются в итоговую подборку
   только при ссылке на них в ответе.
8. Живая проверка выявила дополнительный дефект: старые версии конкурентов
   смешивались с текущими при наличии лишь общих ссылок. Добавлена проверка
   покрытия отдельных предложений с версиями/процентами/ценами и требование
   прочитанной страницы для таких ссылок. Это эвристика покрытия, не доказательство
   смысла утверждения. Kimi получает фильтр sites; сравнение версий — до пяти
   ограниченных ходов вместо трёх. Независимые поиски/чтения выполняются параллельно
   с пределом три и сохранением идентификаторов ответов, без параллельных изменений.
9. Номерные ссылки разрешаются до очистки форматирования Kimi: иначе сама
   очистка удаляла и ссылку, и её карту. Повторная проверка получает реальные
   прочитанные фрагменты из журнала текущего хода (не более 16000 знаков),
   а не только 500-символьные превью. Неудачное точное сравнение автоматически
   эскалирует на Sol при доступности в тарифе; обычные ответы не эскалируют.
10. Для вопросов о версиях добавлен реестр проверенных точек входа официальных
    каталогов OpenAI, Anthropic и Google. Номера моделей не зашиты: читается текущая
    страница. До трёх релевантных каталогов читаются параллельно с таймаутом,
    без домашнего читателя и без платного поискового API. Остальные темы используют
    обычный отбор источников. Непройденная итоговая структурная проверка оставляет
    только подтверждённые ссылками части, а не исходные неподтверждённые ссылки.

## Границы проверки

Структурная проверка URL не доказывает логическое следование каждого утверждения
из источника. Связь по смыслу проверяет модель в процессе чтения/синтеза и
ограниченного восстановления. Она тоже может ошибаться. При неудачном восстановлении
структурно неподтверждённые части исключаются, но корректная ссылка всё ещё не
доказывает истинность всех слов: нельзя объявлять механизм гарантией отсутствия ошибок.
Для полноценного контроля качества нужен постоянно пополняемый набор реальных
вопросов с оценкой полноты ответа, корректности фактов, точности цитат, сохранения
контекста, качества частичных ответов и задержки p50/p95. Процент улучшения без
такой выборки не заявляется. Простой запрет слова «извини» не заменяет эту работу.

## Проверка реализации

Автотесты проверяют числовое уточнение, смену темы, неперенос failed-источника,
сохранение дат, ограничения размера, восстановление после ложного отрицания,
невозможность подложить URL через текст, работу номерных ссылок, отсутствие
лишнего модельного прохода и однократное восстановление с инструментами только
для чтения. Дополнительно запускаются существующие тесты контекста, поиска,
моделей, исследовательских проходов и общих бюджетов.

Финальная живая проверка исходной цепочки прошла за 25,8 секунды: реально
прочитаны три официальные страницы, ответ назвал GPT-6 Astra, Claude Opus 5.5,
Gemini 4 Argon со ссылкой для каждого пункта. Сравнение обозначено как оценка
позиционирования, без заявления о равном качестве или независимом бенчмарке.
Ложного отрицания Muse Wonder и извинений вместо ответа в этом прогоне нет.
Это один регрессионный пример, не статистическое доказательство безошибочности.
Сообщения пользовательской беседы не изменялись; модельные вызовы проверки
учтены на внутреннем Creator. Итоговая версия выложена; резервная копия перед
последним изменением: /root/bitthink-scoped-backup-20261016003855.
Проверены сайт/API, прежние лимиты и счётчики подписок, VPN/nginx и соседние сервисы.

## Общий обзор моделей: регрессия 16.10.2026

Следующий пользовательский запрос «какие щас лучшие модели нейронок в мире?»
сохранился без источников. Причина: классификатор не распознавал разговорную
формулировку общего актуального обзора, а каталог требовал явного запроса
версии и названия производителя. Проверка пустого отказа тоже не срабатывала
при отсутствии любых источников.

Добавлены распознавание общего AI-обзора и разговорных уточнений, прямое чтение
независимого Artificial Analysis и трёх официальных каталогов. Числа и названия
моделей в код не зашиты. Независимый рейтинг не объявляется универсальным:
нужно назвать его критерий, различать модели и режимы reasoning. При отсутствии
рейтинга подтверждённые каталоги позволяют дать обзор без строгой расстановки мест.
Пустой отказ теперь требует одного ограниченного восстановления даже при нуле
источников. Явное «без поиска» отключает новое предварительное чтение.

Новый независимый источник:
[Artificial Analysis LLM Leaderboard](https://artificialanalysis.ai/leaderboards/models).
Тесты включают точный пользовательский запрос, близкие формулировки, английский
вариант, запрет поиска, отсутствие ложного срабатывания на регрессию/нейроны мозга
и обнаружение отказа без источников.

Живая диагностика выявила также ошибку самой структурной проверки: корректная
таблица с общим источником под таблицей считалась набором несвязанных утверждений
и исключалась из ответа. Теперь явная подпись с прочитанным источником покрывает
единый блок таблицы/списка; ссылка в отдельном пункте не распространяется на другие
пункты. Это область действия цитаты, не автоматическая проверка истинности чисел.
Сохранён тест на таблицу с подписью и отрицательные тесты без подписи/с одним
сниппетом вместо прочитанной страницы.

Повторная живая проверка точного общего вопроса прошла за 42,4 секунды:
ответ содержит конкретные модели и показатели с именем индекса, ссылку на
Artificial Analysis и официальные каталоги; оговорка не заменяет сам обзор.
Прочитаны реальные страницы, изменения сообщений беседы не производились.
Последнее исправление выложено; резервная копия:
/root/bitthink-scoped-backup-20261016005605. Серверные тесты и проверки
доступности, подписок, VPN/nginx и соседних сервисов прошли.
