# Студия: экспорт и авторские навыки дизайна

## Экспорт

Старый путь сначала превращал макет в JPEG 1600×900 с quality 0.86. Даже PNG получался из уже сжатого JPEG. Длинные страницы ограничивались высотой 2400 px, а PDF растягивал снимок под заранее заданные пропорции. Маленький размер картинки также мог ошибочно включить подмену дизайна упрощёнными текстовыми блоками в PowerPoint.

Теперь слайды захватываются напрямую в PNG 3840×2160. PDF и PPTX получают тот же снимок без промежуточного JPEG. PNG в PDF сжимается без потерь; на простом тестовом слайде PDF занимает около 71 КБ вместо 25 МБ несжатого изображения. PowerPoint сохраняет визуальное оформление, а не заменяет его другой композицией.

Страницы сначала получают целевую ширину, затем измеряется их полная высота. PDF разбивается на страницы с сохранением масштаба; PNG содержит всю страницу. Для очень больших макетов действует ограничение 24 млн пикселей на снимок и явная ошибка с предложением HTML вместо незаметной обрезки. Снимки остаются растровыми: это не обещание векторного PDF или редактируемого текста в PPTX. Картинка, созданная отдельно, по-прежнему скачивается исходным файлом; дополнительных деталей сверх оригинального разрешения экспорт не придумывает.

Убрано удаление внешних таблиц стилей перед захватом. Класс `.counter` скрывается только при экспорте слайдов, а не у произвольного приложения.

Проверки подтверждают реальное разрешение PNG, размеры встроенного изображения PDF/PPTX, пропорцию 16:9 и наличие нижнего красного блока на третьей странице длинного PDF. Проверены все четыре формата, а не только успешный клик по скачиванию.

## Навыки внутри продукта

Подключены авторские пакеты:

- [UI UX Pro Max — Next Level Builder](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill), commit `28b3b8dee8c976df4fa3e94aed4e092ad43fcb03`.
- [Emil Design Engineering — Emil Kowalski](https://github.com/emilkowalski/skills), commit `2d228630ba1446365f614a108cb8252f1feda202`.

Оба распространяются под MIT. Лицензии, полные исходные инструкции и `SOURCE.json` с версиями и контрольными суммами включены в соответствующие каталоги `computer_skills`. Строки нормализованы в LF для воспроизводимой упаковки Windows/Linux.

Студия автоматически добавляет адаптированные инструкции, результаты настоящего локального BM25-поиска UI UX Pro Max и подходящие разделы Emil в композицию HTML и JSON. Это не только названия в настройках. Подключение проверяется на фактическом пути `_compose_html → compose_with_web`. Дополнительных веб-поисков и отдельных модельных вызовов для выбора правил нет; ограниченная подборка всё же занимает место во входном контексте модели.

Инструкции установки, вступительное приветствие, обязательная таблица ревью и требования внешнего CLI не навязываются пользователю Студии. Бриф и текущий стиль имеют приоритет над примерами из базы. Выключенные пользователем навыки не подгружаются.

## Меню версий

Системный `<select>` заменён доступным меню MUI с цветами, скруглением и выделением BitThink, отметкой выбранной версии и понятными подписями. На кнопке остаётся короткое «Версия N». Меню работает мышью, касанием и клавиатурой; частое переключение не задерживается анимацией.
