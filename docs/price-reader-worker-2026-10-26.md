# Доступ фонового исполнителя к ценам магазинов

Причина: подключение домашнего читателя, его heartbeat и очередь живут в процессе API. После переноса обычных генераций в отдельный исполнитель его локальный экземпляр очереди оставался пустым и считал читателя выключенным. Серверный резерв часто встречал ограничения магазинов; ответ не получал цену из доступной браузеру карточки.

Исправление:

- На время выполнения генерации исполнитель обращается к защищённому API очереди. Настройка `HOME_RELAY_API_URL` по умолчанию равна `http://backend:8000/marketplace-relay` и не требует изменения текущего Docker Compose.
- Процесс API продолжает использовать собственную очередь. Это не создаёт рекурсивных обращений к самому себе.
- Проверка доступности читателя в покупательском сценарии учитывает границу процессов.
- Сохраняются режимы обзорного и полного чтения, кеш успешно прочитанной карточки в рамках запроса и ограничения времени.
- Протокол принимает только поддерживаемые публичные карточки, короткие ссылки и каталоги. Личные кабинеты и произвольные адреса не передаются читателю. Авторизация обязательна; перенаправления и системный HTTP-прокси при внутреннем запросе отключены.
- Контекст маршрута сбрасывается после завершения, ошибки или отмены задания.

В проверяемом контейнере выполнено настоящее чтение карточки Xiaomi 14T на Ozon через подключённый читатель версии 1.9.4. Получен текст карточки с ценами. Это проверка транспорта и извлечения данных, а не обещание постоянного наличия, конкретной цены или отсутствия капчи у всех магазинов. Обычная цена, специальные условия оплаты и платёж рассрочки должны различаться в итоговом ответе.

Автотесты покрывают отдельные экземпляры очереди API и исполнителя, аутентифицированную передачу результата, режим чтения, повторное использование снимка, запрет личных адресов, отсутствие передачи ключа на внешний redirect и установку/сброс контекста настоящим исполнителем.

Проверки кандидата: 969 серверных тестов на новой PostgreSQL, 137 проверок качества и 5 сценариев с экспортом Word прошли. Мигрированная копия базы сохранила 7452 записи в 33 существующих таблицах.
