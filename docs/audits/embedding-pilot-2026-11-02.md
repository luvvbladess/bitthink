# Пилот Qwen3 Embedding 8B: не публиковать текущий вариант

Дата: 2 ноября 2026 года. Пользователь разрешил самостоятельную проверку и публикацию только при оправданном результате.

## Решение

Рабочий поиск и сервер оставлены без изменений. Смысловой поиск заметно улучшил полноту на синтетических материалах, но проверка задержки не прошла заранее установленный порог. Это не доказательство бесполезности embeddings: отклонён именно проверенный вариант с синхронным вызовом API при поиске.

## Условия эксперимента

- 32 коротких синтетических материала типичного проекта: договорённости, документация приложения, инженерные требования, английские инструкции и похожие артикулы. Реальные пользовательские документы не использовались.
- 64 вопроса с известным ответом: 32 для разработки и 32 отложенных. Ещё 12 вопросов без ответа в материалах. Среди положительных вопросов 12 запросов с точными идентификаторами.
- Эталон — неизменённая функция `project_memory.search` из работающего образа. Данные созданы в отдельной SQLite-базе в `/tmp`, до импорта подключения выставлен изолированный DATABASE_URL. Рабочая база не использовалась.
- Кандидат — реальные векторы `qwen/qwen3-embedding-8b` через серверный OpenRouter, 1024 измерения, нормализация и косинусное сходство. Запрос получает рекомендованный производителем retrieval-префикс. Документы индексируются без префикса.
- Гибрид объединяет лексическую и смысловую выдачу через reciprocal rank fusion, константа 20, минимальный cosine 0.55. Совпадения буквенно-цифровых идентификаторов получают приоритет. Параметры зафиксированы до оценки отложенных вопросов и после получения результата не менялись.
- Скорость: 12 последовательных одиночных запросов к API без повторов, с новым HTTP-клиентом на вызов. Это включает сетевые накладные расходы. Модель уже получила пакетные запросы; локальный кеш запросов не использовался.

Условия допуска заранее записаны в фикстуре: прирост Recall@5 на отложенных вопросах не менее 15 процентных пунктов; отсутствие ухудшения Recall@1 по точным идентификаторам; отсутствие увеличения непустых ответов на вопросы без ответа; наблюдаемый p95 одиночного запроса не выше 2 секунд; стоимость API не выше $0.01.

## Результаты

| Проверка | Текущий поиск | Гибрид |
|---|---:|---:|
| Разработка: нужный материал в первых пяти | 12/32 (37.50%) | 26/32 (81.25%) |
| Отложенные: нужный материал первым | 13/32 (40.63%) | 23/32 (71.88%) |
| Отложенные: нужный материал в первых пяти | 17/32 (53.13%) | 26/32 (81.25%) |
| Точные идентификаторы: нужный материал первым | 10/12 | 12/12 |
| Вопросы без ответа: непустая выдача | 5/12 | 5/12 |

Прирост Recall@5 на отложенной части: **28.125 процентного пункта**. Смысловая выдача без лексического дополнения нашла 22/32 отложенных ответа в первых пяти.

Медиана одиночного API-запроса **0.367 с**. Две задержки: **2.782 с** и **9.071 с**; остальные десять — от 0.298 до 0.422 с. Наблюдаемый p95 по методу ближайшего ранга на 12 измерениях составляет **9.071 с**. Выборка мала и не описывает надёжно долгосрочный p95, однако заранее заданный порог в этом прогоне не выполнен.

Стоимость сравнительного эксперимента по возвращённому OpenRouter `usage.cost`: **$0.00004481**, 4397 входных токенов. Отдельный предварительный вызов доступности: **$0.00000048**. Всего: **$0.00004529**. Это стоимость API, без разработки, хранения и генерации конечных ответов.

## Ограничения и возможное продолжение

Проверен поиск документов, а не качество конечных ответов помощника. Короткие синтетические тексты не покрывают большие файлы, реальное распределение вопросов и масштаб хранилища. Контроль прав, удаление и обновление векторного индекса ещё не реализованы, поскольку кандидат не прошёл допуск к внедрению.

Следующий отдельный кандидат мог бы использовать жёсткий срок ожидания, немедленное возвращение к лексическому поиску при таймауте, повторное использование соединений и фоновую индексацию. Тогда потребовался бы новый независимый прогон качества с учётом реально сработавших таймаутов. В этом эксперименте критерии не ослаблялись и ускорение не приписывалось непроверенному решению.
