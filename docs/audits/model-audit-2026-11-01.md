# Модели Bit Think: цена, назначение и проверка качества

Дата проверки: 1 ноября 2026 года. Данные цен меняются; зафиксированный каталог OpenRouter находится в `output/model-audit-2026-11-01/openrouter-models.json` (452 записи). Сравниваются расходы на выполнение задачи, а не только цена миллиона токенов.

## Принятые решения

* Kimi удалён из доступных моделей всех тарифов, включая Creator, из списка исполнителей, интерфейса и Desktop API. Загрузка его ключа отключена. Сохранённый идентификатор `kimi-k2.6` переводится в `search`; поиск выполняют Luna и общий поисковый сервис. Исторические тарифы сохранены только для старых записей расходов.
* Дешёвые кандидаты не добавляются автоматически по месту в рейтинге. Кандидаты этого аудита регистрируются только внутри изолированного тестового процесса, без включения в рабочий пул.
* Luna остаётся основной экономной моделью; Terra — для обычного планирования и зрения; Sol — для сложного кода, исследований и исправлений. Astra и Opus сохраняют узкие экспертные роли. GLM остаётся ограниченным извлечением/классификацией; MiniMax — небольшими правками и файловыми операциями.

## Кандидаты и метод проверки

Дополнительно проверены MiMo V2.6 Pro ($0.435/$0.87), MiMo Flash ($0.14/$0.28), Qwen 3.8 Flash ($0.15/$0.47), DeepSeek V4.1-Flash-1017 через OpenRouter (пиковый предел $0.30/$1.20). Для MiMo встречаются промо-цены, отличающиеся от API-каталога: они не используются как гарантированный тариф.

16 подключений × 6 одинаковых синтетических заданий = 96 ответов: извлечение с вредоносной цитатой, актуальная версия документации, инженерные единицы, SQLite с нулевыми клиентами/дубликатами, деньги через Decimal, чтение двух файлов и применение переопределения. Все текущие 12 текстовых моделей проверены; Kimi исключён по прямому поручению. Используются реальные адаптеры продукта, включая OpenAI Responses, потоковый OpenRouter и продолжение вызовов инструментов. Ключи не передаются в песочницу. В фикстуре чтения содержимое файлов контролируется тестом.

Точные JSON-ответы проверяются без исправления Markdown и пояснений. Поэтому сбой формата отделён от ошибки содержания; это существенно для планировщика и извлечения. SQL исполняется в изолированной памяти с разрешённым только чтением. Сгенерированный Python дополнительно запускается в отдельном контейнере без сети/ключей, с ограничением ресурсов; проверяются реальные значения, отрицательные суммы, округление после суммирования, неизменность входа и ошибки входных данных.

Сырые ответы, время, усилие, провайдер, токены рассуждений, кеш, вызовы и стоимость: `output/model-audit-2026-11-01/screen.json`. Самостоятельные проверки кода: `screen-code-checks.json`. Маленький набор отсеивает явные регрессии, но не доказывает универсальную эквивалентность и не заменяет полноценное сравнение архивов проектов.

MiMo Pro и Qwen нарушили часть контрактов; GLM допустил ошибку прогиба в 100 раз. GLM поэтому не расширен на инженерные задачи. Luna в коротком наборе оказалась дешевле всех прошедших его целиком; замена её более дорогим «Flash» не даёт подтверждённой экономии. Подробные результаты приведены ниже.

## Полные рабочие задачи и итог

Текущий пул прошёл 6/6 сценариев: Python CSV-проект, чтение документации, исправление Decimal с неизменными исходными тестами, Markdown с точными лимитами, проверка инженерных единиц и исследование PostgreSQL по прочитанным первоисточникам. Обе выданные ZIP-сборки независимо распакованы и исполнены; три проверки файлов также пройдены. Стоимость прогона $0.267562 с ограничениями оценки native API.

В контрфактическом эксперименте сотрудники заменялись на MiMo Pro; планировщик, сборщик ответа и защитные проверки сохранялись. Это проверка замены в Bit Think, не отдельный оптимизированный агент Xiaomi.

Другие новые кандидаты также не включены: короткого набора недостаточно для вывода об эквивалентном качестве.

## Экономия без смены модели

В простом совете о подготовке к разговору с руководителем обнаружен лишний цикл: планирование → два исполнителя → повторное планирование → сборка ответа. Содержательно ответ был правильным, но требовал пяти обращений к Luna.

Теперь короткая явно офлайновая подготовка к разговору проходит через один текстовый ответ той же Luna. Файлы, внешние действия, экспертные темы, длинные и непонятные задания исключены из этого сокращения. Модели сложного кода, исследований и CAD не менялись.

На том же вопросе: **5 → 1 вызов**, $0.004624 → $0.000175 и 19.6 → 4.8 с в наблюдаемых прогонах. Ещё три повтора/похожих вопроса дали по одному вызову; ответы вручную проверены на конкретные шаги, нужное число пунктов и пример фразы.

Кеш и вариативность генерации влияют на USD; экономия по всему трафику не установлена. Подтверждённое изменение — устранён ненужный цикл для проверенного класса запросов, без замены модели и снятия защитных проверок.

## Финальные проверки и публикация

* 1306 серверных тестов пройдены; два теста внешнего соседнего Telegram-бота исключены, как и в предыдущей проверке.
* 137 офлайновых проверок качества и 5 продуктовых сценариев пройдены.
* 30/30 повторных пользовательских вопросов и 3/3 дополнительных офлайновых совета пройдены.
* 6/6 специализированных рабочих задач пройдены; две выданные ZIP-сборки дополнительно исполнены.
* 12 проверок интерфейса, включая мобильные 320 px и настольные 1440 px, пройдены; исключений браузера нет. Сборка TypeScript/Vite успешна.
* Kimi удалён из доступных моделей; миграция старых настроек, тарификация истории, Desktop API и режим поиска проверены.
* После публикации проверены маршруты сайта, загружаемые ресурсы, API и готовность фонового обработчика. Новых экспериментальных моделей в рабочем реестре нет.

Первый повторный прогон экономии был настроен без подключения тестовой песочницы; custom harness также получил недостающий timeout. Эти результаты сохранены как `invalid-fixture-*`, исключены из оценки и заменены корректным прогоном с отдельной песочницей. В пользовательском сервисе песочница не отключалась. Первая публикационная проверка ошиблась в служебном импорте; автоматический откат сработал, проверка исправлена и публикация выполнена повторно.

Все ответы и файлы синтетические. Итоговые числа: `output/model-audit-2026-11-01/summary.json`; полные исходные прогоны и выданные артефакты: `evidence.tar.gz`; финальные регрессии: `economy-basic.json`, `advice.json`, `tests-final.xml`. Малая выборка не является статистическим доказательством качества на всех пользовательских задачах.
