# Качество ответов: вычисления, источники и дословность

Основной выпуск — 4 ноября 2026 года, 04:32:04 МСК; исправление дополнительных вариантов оформления цитат — 04:40:49 МСК. Сравнение проведено с уже выпущенной предыдущей версией `355a1b8…`, а не с состоянием до первого раунда улучшений.

## Что изменилось

- Для расчётов по заданным числам подключён точный калькулятор: рациональные числа, десятичное округление, комбинаторика. Модель выбирает формулу, инструмент вычисляет её. Произвольный Python не выполняется; сложность выражений ограничена. Первый вызов вычисления обязателен, последний ход короткого цикла оставлен для ответа.
- Для ограниченных вопросов по официальной документации стандартной библиотеки Python читаются нужные страницы указанной версии напрямую. В уточнениях учитываются функция и версия из истории; при сравнении версий читается также соответствующий журнал изменений. Если нужны больше двух страниц или чтение не удалось, сохраняется обычный путь агента.
- Длинные страницы больше не обрезаются до поиска нужного раздела. Объём отправляемого модели фрагмента остаётся ограниченным; определения API предпочтительнее ссылок на них в навигации.
- Для вычислений предлагается только нужный инструмент. Обычные ответы по документации не запускают отдельные планировщик, команду и сборщик ответа. Существующие модели сохранены; новые платные сервисы не подключались.
- Исправлено повреждение тире в цитатах. При явной просьбе о дословном повторении известный исходный текст восстанавливается только при совпадении слов: никакого угадывания смысла или исправления неверно выбранной реплики. HTML продолжает очищаться.
- Просьба «Только JSON» без глагола также распознаётся как требование формата. Снимается только целиком обрамляющий, проверенный JSON-блок; пояснения и неоднозначные варианты не выбрасываются догадкой.

Использованы открыто описанные принципы: [инструменты OpenAI](https://developers.openai.com/api/docs/guides/tools) и [выбор инструментов Claude](https://platform.claude.com/docs/en/agents-and-tools/tool-use/tool-search-tool). Это не утверждение о закрытой архитектуре ChatGPT или Claude.

## Проверка качества

32 задачи: 12 для разработки, 12 из первоначально отложенной части, 8 дополнительных. Первоначальная отложенная часть использовалась при дальнейшей проверке чтения источников; итоговый набор нельзя считать независимым общим бенчмарком интеллекта. Дополнительные задачи добавлены после первой реализации; финальные исправления формата и границ маршрута затем повторно проверены на всём наборе.

Для каждого режима получены ответы старой и окончательной версий: всего **128 ответов**. Это обычный серверный путь чата с сохранением истории и источников, в изолированном хранилище синтетических пользователей. Рабочие переписки и квоты клиентов не использовались.

| Проверка условий задачи | Экспресс | Оркестратор |
|---|---:|---:|
| До | 20/32 | 26/32 |
| После | 32/32 | 32/32 |
| Дополнительные повторные расчёты после сборки | 36/36 | 36/36 |

**32/32 означает прохождение формальных проверок, а не отсутствие всех смысловых ошибок.** Для числовых ответов проверены точные значения, типы JSON и число десятичных знаков. Десятичная запятая внутри числовой строки допускается, если пользователь не требовал точку. Дословность цитат проверена отдельно от проверки ключевых слов. Другие текстовые задачи требуют содержательной оценки.

72 повторных расчёта — 12 задач × 3 повтора × 2 режима. Все прошли. Есть задачи на дроби, большие целые числа, проценты, вероятности, выбор без возвращения и пересчёт времени из истории.

После основного сравнения проверка выпущенной версии обнаружила дополнительный вариант: модель возвращала известную реплику без кавычек с завершающей точкой. В проверке устойчивости встретилась также лишняя подпись «Вторая реплика:». Исправлен только `services/verbatim_quotes.py`: при явном требовании единственной дословной цитаты восстанавливается совпадающий исходный текст, убирается короткая подпись и учитывается внешняя пунктуация. Модели, их вызовы, калькулятор и чтение справки не менялись. На окончательном образе дополнительно прошли **24/24 повторных проверки цитат**. Исходный неудачный послерелизный ответ и промежуточные проверки сохранены в архиве.

Аудит чтения источников сохранил реальные фрагменты для 11 вопросов, включая различие блокировки `cached_property` до Python 3.12 и после. Поисковая выдача не засчитывается за чтение страницы.

Слепая оценка 18 текстовых пар моделью Claude Sonnet: **12 предпочтений новой версии, 5 старой, 1 равенство**. Все 8 пар с дословными цитатами — в пользу новой версии. Без этих пар результат **4 : 5 : 1**: доказанного улучшения гуманитарной аргументации нет. В частности, встречались более слабое философское возражение, неточная атрибуция и чрезмерно категоричный вывод о доказательстве отсутствия человека на собрании. Маршрут, модель и предметные инструкции для таких недословных гуманитарных ответов в этом релизе не менялись. Один прогон не устанавливает причинного улучшения или ухудшения этого направления.

Модельный судья также ошибается. Шесть первых ответов судьи не разобрались как JSON; те же пары были повторены. Четыре повторных ответа содержали рассуждение перед единственным полным JSON-вердиктом: извлечён только проверенный конечный объект, исходный текст сохранён. Расход первых неразобранных ответов судьи не сохранился, поэтому полная цена эксперимента с судьёй неизвестна. Сравнение стоимости продуктовых ответов от этого не зависит.
