# Подключения и доступы

Когда применять: подключить api, доступ к сервису, управление доступами.

Сначала list_connectors; встроенное подключение предпочтительнее произвольного доступа. Недостающий доступ добавляется в настройках, значения секретов не нужны в ответе или навыке. Используй точную запись владельца и разрешённый сервис. Отказ 401/403 не разрешает переход к более широким полномочиям. Фоновая задача использует только заранее подключённые доступы. Удаляй запись через forget_access только по просьбе владельца и конкретному ID. Подключённый MCP сначала исследуй через mcp_discover.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_access path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
