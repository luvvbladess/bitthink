# Единая модель 2D-чертежей

engineering_build читает spec_path, относительный к личной песочнице. Создай JSON
через workspace_write. Единицы геометрии — мм. Проект содержит sources, facts,
parts и sheets. До40 листов, 200 деталей и 2000 фактов. Чертежи предварительные.

## Источники и факты

sources: объекты с id, name, path, sha256, pages из engineering_import.
В facts: id, value, unit, state, evidence. Ссылка evidence: source_id, page (с1),
quote или locator. Номер page должен существовать. confirmed требует evidence.
assumed — допущение; unknown — только value:null. Для calculated обязательны
expression и inputs — ID фактов. Разрешены арифметические + - * / и скобки,
без Python/eval/функций. Допуск — tolerance, например " H9" или " ±0,1".

Не отмечай confirmed без настоящего источника. Файл источника должен находиться
в песочнице владельца. Источник из слов человека — kind:user, text из его сообщения;
его происхождение проверяется отдельно. Данные по готовому примеру не доказывают
совпадение с оригинальным изделием.

Материалы можно прикреплять прямо в чат: отдельные PDF/DOCX/фото или ZIP.
engineering_import(filename=...) копирует оригиналы в engineering/materials,
сохраняет папки архива и возвращает manifest_path с перечнем ошибок. Старое
вложение без сохранённого оригинала нужно приложить повторно. До200 файлов за
импорт, до20МБ каждый и64МБ распакованных данных; вложенные ZIP не раскрываются.

parts: id, name, designation, qty (целое), required_drawing. Стандартный крепёж
может иметь required_drawing:false. Отсутствующий лист собственной детали попадёт
в отчёт проверки. part_id каждого деталировочного листа должен существовать.
fits: {id,hole,shaft}, где hole/shaft — ID номинальных диаметров фактов; различные
номиналы помечаются конфликтом. Это не полный расчёт полей допусков ISO286.

## Лист и геометрия

sheet: id,title,designation,part_id,material,format A4/A3/A2/A1/A0,
orientation portrait/landscape,scale,views,notes (до8 коротких строк).
Удлинённые форматы: A4x3=630×297мм, A3x3=891×420мм, A1x3=1782×841мм;
используй format из исходного чертежа, а не сжимай всё в A4.
Импорт распознаёт тип шрифта КОМПАС и форматы листов. Ответ возвращает первые20
источников; все остальные находятся в manifest_path (sources_omitted).
Автоматическая спецификация использует семь граф, основную надпись формы2
на первом листе и формы2а на последующих. parts может содержать section, position,
format, zone, note. section по умолчанию «Детали»; не называй сборку деталью,
если её тип известен. Состав и нумерацию позиций бери из источника.
Рамка: 20мм слева, 5мм с остальных сторон; основная надпись185x55мм снизу справа.
Оформление — машиностроительный стиль КОМПАС, основная надпись формы1:
обозначение, наименование, материал, литера, масса, масштаб, лист/листов,
история изменений и графы согласования. Подписи/масса/литера не выдумываются.
organization (уровень проекта) заполняет графу организации, если она известна.
Шрифт OpenGOST с наклоном15°, PDF/SVG содержат его, DXF получает его из fonts
в архиве: установи TTF в CAD для сохранения вида. Это не нативный файл .cdw.
Пользовательский шаблон .lyt автоматически не импортируется.
Рабочая область: x>=22, x<=ширина-7, y>=22, y<=высота-66.
Под примечания оставь дополнительный свободный ряд внизу.

view.origin — [x,y] на бумаге, от левого верхнего угла листа в мм.
Внутри view координаты декартовы: X вправо, Y вверх, реальные размеры детали в мм.
view.scale переопределяет sheet.scale. Высота текста/толщина линии — мм на бумаге.
В DXF модель содержит геометрию деталей1:1 в мм, а лист Drawing — её вставки
в масштабе чертежа, рамку и надписи.
Типы entities:
- line: from,to; style:center — осевая; width .1..1.5; layer.
- circle: center,radius.
- polyline: points,closed; hatch:true только для замкнутого контура.
- arc: center,radius,start_angle,end_angle (градусы против часовой стрелки).
- text: at,text,height (обычно3.5),anchor:start/middle/end.
- leader: points,text,position_ref (ID детали из parts).
- linear_dim: from,to,axis:x/y,offset,fact_id,prefix (не подменяй число).
  offset — смещение размерной линии в мм бумаги, независимо от масштаба; отрицательное
  значение для горизонтального размера означает линию выше точки, для вертикального — левее.
- diameter_dim: center,radius,fact_id. Значение обязано равняться двум радиусам.

Любой размер связан с fact_id и сравнивается с геометрией, погрешность0.01мм.
Ручной text у размера запрещён. Значение assumed получает подпись «доп.»;
calculated — «расч.»; unknown — вопросительный знак. Для реальных измерений
пользуйся источником, а не статусом assumed только ради обхода проверки.

## Минимальная иллюстрация схемы (вымышленный цилиндр)

```json
{"title":"Пример цилиндра","designation":"DEMO.001","include_bom":false,"sources":[],
 "facts":[{"id":"length","value":32,"unit":"mm","state":"assumed"},
          {"id":"diameter","value":17,"unit":"mm","state":"assumed"}],
 "parts":[{"id":"armature","name":"Цилиндр","qty":1}],
 "sheets":[{"id":"detail","part_id":"armature","title":"Цилиндр", "format":"A4","scale":2,
 "views":[{"origin":[70,120],"entities":[
 {"type":"polyline","points":[[0,-8.5],[32,-8.5],[32,8.5],[0,8.5]],"closed":true},
 {"type":"line","from":[-5,0],"to":[37,0],"style":"center","width":0.18},
 {"type":"linear_dim","from":[0,8.5],"to":[32,8.5],"axis":"x","offset":-8,"fact_id":"length"},
 {"type":"linear_dim","from":[0,-8.5],"to":[0,8.5],"axis":"y","offset":-10,"fact_id":"diameter","prefix":"Ø"}]}],
 "notes":["Учебный пример: значения придуманы, не размеры оригинала."]}]}
```

Результат: drawings.pdf, engineering-package.zip, sheets/*.svg и *.dxf,
project.json, bom.csv, traceability.md, validation.json. По умолчанию перечень
деталей автоматически добавляется в PDF (по22 позиции на страницу); include_bom:false
отключает его только для отдельно заказанной детали. DXF — редактируемая 2D-геометрия
и размерные тексты, без ассоциативных DIMENSION; дуги экспортируются полилиниями.
После успешной сборки инженерное чтение PDF обязательно; никакого imagegen.
