# Проверка перед завершением

Адаптация Verification Before Completion из obra/superpowers (MIT). Оригинал — upstream-verification.md, версия и лицензия — ../SOURCE.json.

Свяжи каждое существенное утверждение с его проверкой: «собирается» — код выхода build, «ошибка исправлена» — исходный сценарий, «тесты прошли» — фактический запуск с количеством выполненных тестов. Линтер не заменяет компиляцию, успешная установка зависимостей не заменяет запуск, слова другого исполнителя не заменяют результат инструмента.

Проверяй сохранённую текущую версию после последней содержательной правки. Если исходники не менялись после уже выполненной проверки, не повторяй дорогой полный прогон лишь ради финальной фразы. Сначала прочитай результат, затем формулируй статус. Отличай ожидаемый ненулевой выход на плохих входных данных от провалившейся сборки.

Для архива проверь наличие README, тестов, исходников и манифеста зависимостей. Не клади node_modules и venv. Для веба отдельно проверь основное действие и узкий экран. Успех локальной сборки не подтверждает публикацию сайта. При недоступной среде выдай исходники с точным описанием непроверенной части.
