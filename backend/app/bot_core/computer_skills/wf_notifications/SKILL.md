# Политика уведомлений

Когда применять: уведомляй только об изменениях, не уведомляй без изменений, настрой уведомления.

Результат фоновой задачи сохраняется в беседе. Отдельные каналы push/email/SMS нельзя обещать без рабочего адаптера и выбора пользователя. Для мониторинга обозначь, какое изменение значимо; при неизменном состоянии не создавай повторные длинные уведомления. Техническая доступность почты не является просьбой отправлять письма. Не меняй общие настройки аккаунта из фонового запуска. Запись результата и доказанная доставка уведомления различаются.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_notifications path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
