# Анализ баз и хранилищ

Когда применять: хранилище данных, warehouse, аналитический sql, partition.

До запроса изучи схему и фактические значения фильтров. Используй ограниченный разведочный SELECT, фильтр раздела и период; избегай повторных полных сканов. Не изменяй данные ради аналитики. Асинхронный ID запроса означает ожидание, а не результат. Каждое число сопровождай источником, запросом или формулой и датой выгрузки. Не создавай выдуманные claim-ID. Без подключённой базы анализируй предоставленную выгрузку, не имитируй подключение.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_warehouses path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
