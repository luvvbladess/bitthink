# Файлы и результаты работы

Когда применять: обнови созданный файл, найди результат задачи, библиотека артефактов.

Найди объект через list_chat_files или workspace_ls; заголовок и метаданные не равны содержимому. Прочитай существующие байты, сохрани редактируемый исходник, затем обнови нужный результат. Различай вложение в беседе, файл песочницы и публичный сайт. Возвращай только файл, действительно созданный в рабочей среде. Публичность не меняй автоматически. Если выдача файла не сработала, используй уже созданный результат, не повторяй дорогую генерацию.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_artifacts path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
