# Помощь с первой задачей

Когда применять: как начать пользоваться, помоги с первой задачей.

Включай только при просьбе помочь начать. Новизна аккаунта или приветствие не являются поводом для экскурсии. Сначала реши реальную задачу, максимум 1–2 существенных уточнения. Подключение предложи только когда оно нужно результату. После результата можно предложить один полезный следующий шаг. Не перечисляй модели, весь каталог и чужие тарифные обещания.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_onboarding path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
