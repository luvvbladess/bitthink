# Работа с данными здоровья

Когда применять: данные здоровья, healthkit, данные фитнес-браслета.

Штатного подключения HealthKit/медицинских карт в БитСинк нет. Используй предоставленную пользователем выгрузку либо реальный разрешённый MCP-источник, сначала изучив его схему. Не выдумывай показатели, диагнозы и факт подключения. Различай наблюдения данных и медицинские выводы. Для важных медицинских утверждений нужны актуальные авторитетные источники и контекст пользователя.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_health path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
