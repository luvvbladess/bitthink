Нужны base_url и токен (или уже сохранённый доступ type=http). Не проси настройки.

Инструмент: `http_request`. method, path относительно base_url, для записи – json_body строкой JSON.

Порядок:
1. Если доступов нет – возьми URL и токен из сообщения. После первого вызова они сохранятся.
2. Сначала узкий GET (health, /me, конкретный id). Не выгружай всю коллекцию «на всякий случай».
3. Ответ обрезается. Большой JSON пиши в песочницу и считай скриптом (`workspace_write` + `python_run`), в чат – короткий итог.
4. 401/403 – неверный токен или схема. Не подбирай чужие ключи. Скажи, какого заголовка не хватает.
5. POST/PUT/PATCH/DELETE – только если пользователь явно просит изменить данные.

Нельзя:
- ходить на другой хост, чем base_url;
- печатать токен в ответ;
- подменять API браузером, если есть JSON-эндпоинт.
