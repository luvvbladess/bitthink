Используй только фактически обнаруженные ошибки и повторы; не запускай дорогой самоаудит без повода. Сначала исправь результат текущей задачи. Затем предложи минимальную правку личного навыка, либо сохрани её, если пользователь прямо поручил изменение. Не меняй общий навык и не ослабляй проверки. Сравни положительный и отрицательный пример триггера.

Это личный профиль: текущая просьба пользователя и правила среды приоритетны.
