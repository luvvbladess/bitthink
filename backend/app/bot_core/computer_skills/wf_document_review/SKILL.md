# Проверка документов по утверждениям

Когда применять: рецензия документа, проверь утверждения документа, разметь замечания.

Сначала прочитай все разделы и составь список проверяемых утверждений с точным текстом и страницей/якорем. Проверь их по первичным источникам: подтверждено, опровергнуто, недостаточно данных. На одно спорное утверждение 2–3 целевые попытки; затем фиксируй неопределённость. Замечание содержит место, важность, основание и предлагаемую правку. Общую причину не дублируй как десятки независимых ошибок. Итоговый файл с аннотациями прочитай обратно; без рендера не утверждай, что визуально всё проверено.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_document_review path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
