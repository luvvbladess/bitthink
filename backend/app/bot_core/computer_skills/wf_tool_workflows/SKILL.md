# Пакетная обработка инструментами

Когда применять: пакетная обработка api, обработай все страницы api, объединить выгрузки.

Сначала mcp_discover или схема доступного API, затем один небольшой тестовый вызов. Не предполагай, что Python песочницы может вызывать инструменты сервера: если шлюза нет, получи данные через mcp_call/http_request и обработай их python_run. Пагинацию выполняй до исчерпания курсора, дедупликацию по стабильному ID. Ограничивай параллелизм, обрабатывай rate limit с паузой; отказ доступа не исправляй повторными входами. После сомнительного результата записи сверяй состояние. Верни краткую сводку и файл, сохрани происхождение строк.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_tool_workflows path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
