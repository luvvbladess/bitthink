# Импорт локальных правил

Когда применять: импорт локальных навыков, перенеси правила из codex, импорт из claude.

Сначала проверь подключение BitClient и desktop_skill_list; Windows не требует чужого Mac-установщика. Прочитай выбранный пакет и его ресурсы, отдели инструкции от личных доступов. Перенос выполняй по списку пользователя; не копируй все локальные папки. Сохрани описание, область и безопасные ресурсы. Если серверного импортера выбранного локального пакета нет, подготовь переносимый ZIP или инструкции; не утверждай, что память и коннекторы перенесены.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_local_import path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
