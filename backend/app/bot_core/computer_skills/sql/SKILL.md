---
name: sql
description: Разобрать или написать SQL, проверить на данных в песочнице. Не ходить на чужую прод-базу.
---

Порядок:
1. Уточни диалект только если без этого запрос ломается (Postgres / SQLite). Иначе пиши обычный SQL.
2. Нет живой БД в чате – не выдумывай строки. Сделай пример на sqlite в песочнице или разбери запрос текстом.
3. SELECT сначала. DELETE/UPDATE/DROP не предлагай «на всякий случай».
4. Большой разбор лога или дампа – скрипт, в чат итог.

Нельзя: подключаться к localhost и внутренним хостам, просить пароль БД в ответ, строить SQL-injection «для теста» на живых системах.
