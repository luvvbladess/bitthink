# Работа на устройстве через BitClient

Когда применять: на моём компьютере, в bitclient, локальное приложение.

Облачная песочница и компьютер пользователя различаются. Сначала прочитай доступные desktop-инструменты и локальные навыки через desktop_skill_list/read. Не считай домашний читатель доступом к файлам компьютера. Используй только подключённое устройство и указанную рабочую папку. Локальные изменения выполняй последовательно; ожидай существующую операцию, не запускай копию после тайм-аута. Перед записью прочитай файл и сохрани изменения пользователя. Установку программ выполняй только в пределах явного поручения.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_device path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
