name: studio_render
description: Как вызвать движок Студии – studio_build, картинки, composed. Грузи перед финальной сборкой файла.
---

Цель: получить реальный файл в чате (кнопка скачивания), а не описание «как бы выглядело».

Порядок:
1. У тебя уже есть валидный JSON (`kind: deck` или `kind: infographic`) после скилов `visual_system` + `deck`/`infographic`.
2. Вызови инструмент `studio_build` с полем `spec` – целиком JSON-объект (строкой или как требует схема инструмента).
3. Движок сам: нормализует схему → генерирует AI-картинки по `image_prompt` / `elements[].prompt` (если есть квота) → рендерит PPTX/PNG.
4. Если `studio_build` недоступен: запиши `workspace_write` путь `studio/spec.json`, затем попроси режим Студии.
5. После успеха коротко опиши, что внутри файла (число слайдов / тип инфографики / тема / были ли картинки). Не дублируй весь текст слайдов в чат.
6. Запрещено писать «архив готов» / «скачайте по ссылке», если инструмент не вернул успех.

Ошибки схемы:
- неизвестный `layout_id` – исправь по каталогу deck/infographic (poster, mosaic, metric_row, visual, composed);
- слишком длинный текст – сократи;
- composed без 2+ элементов – добавь;
- мало шагов/KPI – добери из брифа или уточни у пользователя карточками;
- нет картинок из-за лимита – файл всё равно соберётся без изображений, скажи об этом честно.

Превью PNG для презентации движок может приложить сам – не генерируй вторую кустарную картинку вручную.
