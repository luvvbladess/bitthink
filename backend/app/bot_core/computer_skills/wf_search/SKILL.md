# Поиск с проверкой источников

Когда применять: найди первоисточник, проверь источники, исследуй вопрос.

Разбей вопрос на конкретные сущности; для каждой используй подходящий поиск. Переформулируй один вопрос ограниченно, а не бесконечно. Выдача выбирает кандидатов, browse_page читает содержание. Сохрани фактический URL, дату и подтверждающий фрагмент; при конфликте открой первичные источники. Поисковый сниппет, чтение страницы и проверка конкретного предложения различаются. Не генерируй адреса. Для маркетплейсов загрузи marketplaces: ограничение 20 текстов отзывов, доставка и выбранный продавец проверяются отдельно.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_search path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
