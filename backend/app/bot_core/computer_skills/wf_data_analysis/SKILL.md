# Статистический анализ и графики

Когда применять: статистический анализ, построить график, проверка гипотез.

Проверь схему, типы, пропуски, дубликаты, единицы измерения и размер выборки. До расчёта зафиксируй метод и его предпосылки; корреляция не доказывает причинность. Выполняй преобразования и расчёты python_run, сохрани воспроизводимый код и исходные данные. Покажи формулы, доверительные интервалы где уместно, ограничения и вывод по вопросу пользователя. График должен иметь подписи, единицы и честную шкалу; доступная таблица дополняет изображение. Для базы загрузи warehouses.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_data_analysis path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
