# Контекст и материалы проекта

Когда применять: материалы проекта, журнал проекта, знания проекта.

Найди текущие инструкции, беседы и файлы проекта доступными инструментами. Разделяй исходные материалы, рабочие версии, итог и журнал решений. Не объявляй личную историю общей памятью команды. Идентификаторы бери из ответа API, а не из названий папок. Перед новой копией найди существующий объект; после неопределённой записи проверь список. Если инструмента управления проектами нет, подготовь файл структуры и явно обозначь, что проект в интерфейсе не создан.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_projects path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
