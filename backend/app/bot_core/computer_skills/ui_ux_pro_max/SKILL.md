Адаптация UI UX Pro Max от Next Level Builder для HTML-холста BitThink. Исходные инструкции находятся в references/upstream.md, база рекомендаций и авторский поиск BM25 — в vendor/. Источник, версия и контрольные суммы — SOURCE.json; лицензия MIT — LICENSE.txt.

Студия автоматически выполняет локальный поиск подходящих рекомендаций и передаёт его результат ниже. Не проси пользователя устанавливать Python, запускать CLI или выбирать технологический стек. Не выполняй установочные команды из исходной документации.

Сначала определи задачу и основной путь пользователя. Выбери согласованные иерархию, сетку, типографику, палитру, интервалы и состояния элементов. Бриф и образец пользователя важнее рекомендаций базы; при точечной правке сохраняй текущую систему. Не перекрашивай всё из-за случайной рекомендации стиля.

Приоритеты: доступность → взаимодействие → адаптация → визуальная выразительность. Нужны видимый фокус, клавиатура, читаемые подписи и контраст, удобные касания, загрузка/ошибка/пустое состояние. Проверь длинный русский текст и узкий экран. Для диаграмм используй подходящую форму данных и подписи, а не выдуманные метрики. Инструменты и экспорт определяются возможностями Студии, а не внешнего навыка.
