# Независимая проверка сложного решения

Когда применять: независимые мнения, совет экспертов, сравни подходы независимо.

Для сложного спорного решения Оркестратор назначает независимых специалистов из разрешённого тарифом пула автоматически. Пользователь не выбирает модели. Ветви получают одинаковый вопрос и ограничения, прежде синтеза не копируют выводы друг друга. Итог разделяет согласие, противоречия и уникальные аргументы; провал ветви явно уменьшает полноту. Минимум два фактических успешных ответа для заявления о независимом сравнении. Один повторённый ответ не является советом.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_council path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
