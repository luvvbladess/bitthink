# Фоновые задачи и расписания

Когда применять: каждый день, каждую неделю, следи за ценой, завтра напомни, по расписанию.

Создавай расписание только по просьбе работать позже, повторять или следить. Установи точное поручение, интервал и начало; дату переведи в Unix timestamp с часовым поясом пользователя, неоднозначность уточни. task_create сохраняет задачу, task_list показывает реальное состояние, task_control ставит на паузу/продолжает/отменяет точный ID. Минимальный повтор — 5 минут, максимальный — 30 дней; это интервал, не календарный cron. Проверяй возвращённый next_run_at. Нет штатного триггера по событию и гарантированной отправки SMS/email. Не создавай вложенные расписания из фонового запуска; не называй запись задачи уже выполненной работой.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_automations path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
