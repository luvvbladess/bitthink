---
name: ssh
description: Команды на VPS пользователя по хосту, логину и паролю или ключу из чата.
---

Инструмент `ssh_exec`. Передай host, username и password либо private_key из сообщения. Не проси заранее сохранять сервер в настройках.

Безопасность:
- только хост из сообщения пользователя, не чужие IP «для примера»;
- сначала безобидные команды: uname, df, systemctl status, ls нужного каталога;
- деструктивные (rm -rf, mkfs, drop database, reboot) – не выполняй, пока пользователь явно не подтвердит этой фразой;
- вывод обрезается; если нужно продолжить – следующая узкая команда;
- ключи и пароли в ответ не печатай;
- localhost и внутренние адреса инструмент отклонит.

Если команда упала – верни stderr коротко и предложи следующий шаг, не эссе про Linux.
