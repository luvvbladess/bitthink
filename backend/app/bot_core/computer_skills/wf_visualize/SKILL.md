# Наглядные объяснения

Когда применять: интерактивная визуализация, визуализируй процесс, наглядная модель.

Одно объяснение — одна понятная визуализация с одной целью. Точные данные и научные графики рассчитывай кодом. Для поддерживаемых объектов используй studio_build и существующий холст Студии; не вставляй произвольный HTML/JS в доверенный интерфейс чата. Проверь размер, подписи, узкий экран, светлую/тёмную тему и reduced motion. Сложное приложение требует отдельного файла/проекта; не называй рисунок рабочим приложением.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_visualize path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
