# Чтение сайтов и действия в браузере

Когда применять: прочитай сайт, проверь страницу, действия в браузере.

Для публичной страницы используй browse_page; для РФ-маркетплейса при подключении используется домашний читатель. Авторизованная сессия требует соответствующего коннектора или BitClient. Инструмент чтения не означает возможность кликать и оформлять заказ. Предпочитай семантический элемент и ожидание события доступного браузера, ограничь повторы. После действия прочитай изменённое состояние. Закрывай только вкладки агента, сохраняй вкладки человека. Не объявляй обход антибота гарантированным.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_browser_workflow path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
