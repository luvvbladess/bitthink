# Работа с подключённым Databricks

Когда применять: databricks.

Штатного Databricks CLI и аутентифицированного workspace в песочнице нет. Проверь реальный MCP/API-коннектор; без него доступен анализ выгрузки или проект команд. Не читай и не перенастраивай чужие профили. Для рабочего адаптера сначала schema/help, затем небольшой read-only запрос. Сохраняй ID долгой операции и проверяй его состояние. Отказ прав не обходи переподключением. После тайм-аута изменения выясни состояние до повторного запуска.

Перед работой проверь фактический каталог инструментов. Загрузи read_skill_resource skill=wf_databricks path=references/contract.md только когда нужна схема проверки или ограничение подключения. Не загружай остальные навыки целиком. Инструкции пользователя и профильные навыки БитСинк имеют приоритет.
