# Матрица качества ответов

90 сценариев: 15 тем × 6 режимов. Экспресс — auto, Поиск — search,
Исследование — gpt-6-sol, Astra — gpt-6-astra, Оркестратор — director,
Документы — docgen. Последний режим внутренний. Студия в эту матрицу
текстовых ответов не входит: для артефактов есть specialized и canvas_chat.

Темы: математика, физика, программирование, медицина, финансы, право,
история, письма, анализ данных, поиск исследований, актуальные сведения,
выбор товаров, неопределённость, внедрение инструкций в данные, обучение.
Одинаковые вопросы позволяют сравнивать режимы. Это проверка качества
текстового ответа, не проверка доставки DOCX или других артефактов.

Из каталога backend, подготовка без вызовов моделей:

    python -m evals.answer_matrix --report ../data/answer-matrix-plan.json

Платный прогон через существующий исполнитель evals.live:

    python -m evals.answer_matrix --live --modes auto,search --topics math,search_current --max-usd 1 --report ../data/answer-matrix.json

Без --modes и --topics выбирается вся матрица. Требуются настроенные
провайдеры, БД и внутренний аккаунт Creator. Используется обычный учёт
расходов аккаунта; история вопросов синтетическая. Запускать отдельным
процессом, не внутри обслуживающего сервера.

Основной отчёт сохраняет ответы, источники, ошибки, время, стоимость и
замечания оценщика. Файл .summary.json группирует проблемы по режиму и
теме и показывает, что улучшать. Критерии review_criteria передаются
оценщику вместе с вопросом. Проверки формата и явных чисел дополняют его.
Не считайте совпадение ключевых слов доказательством правильности.

Бюджет останавливает запуск следующих вопросов, но не ограничивает
стоимость уже начатого вопроса и оценщика. Незавершённая матрица явно
отмечается в сводке. Актуальные ставки и цены не зафиксированы в эталоне:
оценщик сопоставляет ответ с полученными страницами. Его замечания нужно
проверять человеком; unknown означает недостаток доказательств.

    python -m unittest discover -s tests -p test_answer_matrix.py
