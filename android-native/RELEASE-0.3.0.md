# Bit-Think Android 0.3.0

Нативный клиент на Kotlin. WebView не используется. Название и логотип сайта
сохранены. APK тестовый, Android 8.0+, targetSdk 36, versionCode 6.

## Что изменено

Подключение переключено с несуществующего `/api/chat/ws` на `/chat/ws`.
На опубликованном сервере первый адрес возвращает HTTP 404, второй допускает
WebSocket-handshake и отклоняет тестовый недействительный токен кодом 1008.
Настоящий пользовательский токен для этой проверки не использовался.
Добавлена нарастающая задержка повторного подключения. Ошибки 401/403
авторизации переводят на вход, вместо бесконечного восстановления сессии.

Шапка получила логотип сайта. Вопрос отображается заголовком, ответ — статьёй.
Поле сообщения сделано без плавающей подписи, с отдельной строкой для
вложения, режима и отправки. Длинное название режима сокращается, не
заезжает на соседние кнопки. Успешное соединение не отображается постоянной
надписью «На связи». Родные Material-компоненты и системные темы сохранены;
это приближение к мобильному сайту, не подтверждённая визуальная копия.

## Проверки

Сборка, Android Lint и 25 автоматических проверок прошли:

- 14 проверок Android Views на API 28/35, в том числе узкое окно 320 dp,
  fontScale 1.3, длинный режим без пересечения с отправкой, поток и прокрутка.
- 6 проверок запросов к локальному HTTPS MockWebServer: PATCH/DELETE,
  multipart-поля, заголовок авторизации, DOCX POST и запись байтов, ошибки
  сервера, отклонение небезопасных ссылок.
- 5 проверок экранов с ответами по контрактам API: массив файлов, профиль и
  тариф, сохранение имени, память, активация инструкции, восстановление беседы.

Тесты используют управляемые ответы; это не подтверждение полного рабочего
сеанса с настоящим аккаунтом на опубликованном сервере. Пароли и пользовательские
сессии в тестах не использовались. Lint-предупреждения оставлены видимыми.

Подключённого телефона нет. Эмулятор ранее не загрузился без гипервизора.
Поэтому установка, реальный вход, диалог с моделью, физическая клавиатура,
жесты, сохранение/отправка в другие приложения и плавность кадров ещё
должны пройти проверку на устройстве. 0.3.0 не объявляется магазинным выпуском.

## Короткий обзор движения

| Before | After | Why |
| --- | --- | --- |
| Поле с плавающей подписью и тесными кнопками | Текст и действия разнесены по вертикали | Убирает конкуренцию за место |
| Бесконечное восстановление после неверного маршрута | Правильный маршрут, backoff, выход при недействительной сессии | Ошибку сервера не маскирует анимация подключения |
| Перерисовка Markdown на каждый фрагмент | Пакетное обновление текста, разбор готового ответа вне UI-потока | Не нагружает каждый кадр |

Переходы остались стандартными Material fade-through 180 мс с учётом
системного отключения анимаций. Измерение частоты кадров на телефоне отсутствует.
