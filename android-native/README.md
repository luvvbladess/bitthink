# Bit-Think — нативный Android-клиент

Текущая версия: **0.5.0**, Kotlin / Android Views / Material 3.
Android 8.0+, targetSdk 36. Основной интерфейс нативный; WebView используется
только для просмотра созданных HTML-результатов.

Последние изменения и проверка на Pixel 7a: [RELEASE-0.5.0.md](RELEASE-0.5.0.md).
Состав функций: [RELEASE-0.3.0.md](RELEASE-0.3.0.md).
Документ ANDROID-QUALITY.md относится к предыдущей версии 0.2.0.

В 0.3.0 добавлены режимы, управление и поиск бесед, корзина, файлы,
экспорт Word, профиль, тариф, память и инструкции. Исправлен опубликованный
WebSocket-маршрут. Все 39 текущих локальных автоматических проверок прошли.
Сохранённая авторизация, реальный ответ, клавиатура и панели проверены на устройстве.

## Сборка

JDK 17, SDK 36 / Build Tools 36.0.0, Gradle 8.11.1, AGP 8.10.1.
Указать sdk.dir в local.properties:

    .\gradlew.bat assembleDebug lintDebug testDebugUnitTest

На Windows тестовый JVM может не найти классы в пути с кириллицей.
Для этой сборки исходники скопированы без build/.gradle в
%LOCALAPPDATA%/BitSync/source. Изменять следует исходники этого репозитория.

Тестовая debug-подпись совпадает с 0.2.x; APK можно установить поверх.
В 0.5.0 добавлены просмотр изображений и PDF, HTML-холст и уведомления
о завершении отправленных из приложения задач. Проверены пять сценариев
на реальном устройстве, включая загрузку файлов в беседу и переход из уведомления.
Полноценные проекты, Office-редакторы, интеграции, автоматизации,
платежи и серверные push через FCM ещё не перенесены. Это не готовый магазинный выпуск.
