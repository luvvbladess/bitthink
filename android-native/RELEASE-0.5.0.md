# Bit-Think Android 0.5.0

3 ноября 2026. versionCode 11, targetSdk 36. Установлено поверх предыдущей
версии на Pixel 7a с Android 17; сохранена прежняя тестовая подпись.

## Что добавлено

- Картинки в сообщениях: миниатюра и открытие в нативном просмотрщике,
  увеличение двумя пальцами, перемещение и двойное касание.
- PDF открываются внутри приложения с перелистыванием страниц. Разбор PDF
  выполняется отдельным изолированным процессом без доступа к аккаунту и сети.
- Холст результатов доступен из меню беседы и карточек в сообщениях.
  HTML-страницы, инфографика и презентации открываются внутри приложения;
  для презентаций предусмотрены переключение слайдов и счётчик.
- Из просмотрщика можно сохранить файл или поделиться им. Для HTML можно
  написать пожелание и перенести его в черновик чата вместе с контекстом результата.
- При сворачивании приложения во время отправленной задачи появляется
  уведомление о готовом ответе; нажатие открывает соответствующую беседу.
  В открытом приложении отдельное уведомление о завершении не показывается.
- Убраны дублирующие имя файла подписи рядом с карточкой вложения.

HTML-просмотрщик используется только для документов, а не для интерфейса
клиента. У него нет JavaScript-моста к приложению, доступа к локальным файлам,
аккаунту, камере или микрофону. Запросы fetch, формы и вложенные фреймы
заблокированы; внешние HTTPS-ссылки по нажатию открываются в браузере.

## Проверка

Сборка и 39 локальных тестов прошли: 6 контрактов API, 18 UI-проверок,
7 экранов рабочего пространства и 8 проверок результатов/уведомлений.
Android Lint: 0 ошибок, 39 предупреждений; предупреждения не подавлялись.

На подключённом телефоне прошли пять инструментальных сценариев:

1. Открытие изображения и проверка отображённого bitmap.
2. Изолированный рендер двух страниц PDF и переключение страницы.
3. HTML-презентация: ограничения WebView, переключение слайда и содержимое.
4. Загрузка PNG, PDF и HTML через настоящий API в отдельную тестовую беседу,
   затем открытие каждого результата из его карточки в чате.
5. Настоящий запрос модели, сворачивание, получение уведомления, нажатие
   в системной панели и проверка идентификатора открытой беседы.

Промежуточные прогоны выявили несовместимость учёта ActivityScenario с
возвратом из системного уведомления: сценарий проверял уже неактуальный
экземпляр Activity. Финальная проверка проверяет реально возобновлённую
Activity и её беседу, и прошла. Производственный код ради теста не обходился.

Отчёты: output/android/quality-0.5.0 и output/android/device-check.
В аккаунте оставлена отдельная беседа «Проверка результатов Android» с
тестовыми файлами; пользовательские беседы не удалялись и не редактировались.

## Границы версии

Уведомления используют временную foreground-службу для задач, отправленных
из приложения, и прекращают опрос после завершения. Это не FCM: доставка
после принудительной остановки приложения или для задач, запущенных только
на сайте, не реализована. Длительные ограничения Android действуют.

Просмотр Office использует серверные изображения страниц; отдельный Office-
редактор не перенесён и не проходил физическую проверку в этой версии.
HTML-результаты, которым нужны авторизованные сетевые запросы или iframe,
могут отображаться не полностью из-за ограничений просмотрщика.
Проекты, интеграции, автоматизации и платежи пока не перенесены.
APK имеет debug-подпись и предназначен для тестирования, не для Google Play.
