Домашний читатель Bit-Think — Windows 10/11 (64-bit)

1. Перенеси ZIP на постоянно включённый компьютер со Smart Telecom.
2. Распакуй архив целиком в папку. Не запускай INSTALL.exe прямо внутри ZIP.
3. Запусти INSTALL.exe обычным пользователем. Администратор не требуется.
   В программе уже есть Python и зависимости. Используется установленный
   Chrome/Edge с отдельным профилем. Если их нет, загрузится отдельный Chromium.
4. Через 10–20 секунд запусти STATUS.bat. Ожидается HOME READER ONLINE.
5. Отправь в Bit-Think настоящую ссылку на карточку товара.

Маркетплейсы должны открываться напрямую через Smart Telecom.
Нынешние отдельные правила для OpenAI менять не требуется.
Если VPN перехватывает весь трафик, настрой прямой маршрут для маркетплейсов.
Программа сама VPN, маршруты и роутер не меняет.

Получает только ссылки разрешённых маркетплейсов, читает их отдельным браузером
и отправляет текст на https://bit-think.space. Ключей OpenAI и доступа к личному
профилю в ней нет. Порты не открывает. Покупки, входы в аккаунт и нажатия кнопок
не выполняет. Если появится капча, открой отдельное окно браузера на панели задач
и пройди её вручную. Затем повтори запрос со ссылкой в Bit-Think.

Окно браузера может запускаться свёрнутым. Для остановки используй STOP.bat.
START.bat запускает программу снова. UNINSTALL.bat остановит её и уберёт
автозапуск; профиль и журнал останутся в %LOCALAPPDATA%\BitThinkHomeReader.
Автозапуск срабатывает после входа этого пользователя в Windows.
Если компьютер выключен, спит или нет интернета, сайт использует резерв.

Для диагностики отправь вывод STATUS.bat. Не отправляй config.json: в нём ключ
подключения. Этот архив с ключом не следует публиковать или пересылать посторонним.

Серверная часть и протокол проверены. Доступность настоящих карточек через
Smart Telecom проверим после установки: капчи возможны и на домашнем IP.
